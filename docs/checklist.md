# 手动验收清单

本清单对应实施计划的 M0–M7 里程碑与边界用例。自动化部分由 `npm run check`（`tsc --noEmit && eslint . && vitest run`）覆盖；以下项目需人工在浏览器中确认。

运行方式：`npm run dev` 后打开 `http://127.0.0.1:5173`。`scripts/qa.cjs` 是 Playwright 冒烟脚本（需先启动 dev server），截图输出到 `qa/`。

## 通用冒烟（M0/M6）

- [ ] 打开首页无 console error，菜单正常显示。
- [ ] `canvas` 以 16:9 居中、像素锐利（无模糊拉伸）。
- [ ] 桌面 1280×800 与手机 390×844 视口下都能看到完整画面。

## 移动与碰撞（M1）

- [ ] WASD 与方向键都能四向移动；撞墙/建筑/水面停止，不穿模。
- [ ] 相机跟随玩家且不越出地图边界。
- [ ] 手机左下摇杆可移动，死区内不漂移；右下 E 按钮可交谈。
- [ ] 竖屏时有"横屏体验更佳"提示且不阻塞操作。

## 进楼与存档（M2）

- [ ] 走到图情信息中心/弘医楼/临江书院/大学科技园/雅园食堂门口，淡出淡入进入对应室内。
- [ ] 室内走到"出口"回到室外，位置回到进门前附近。
- [ ] 连续切图往返 5 次，`window.__game.scene.getScene('World').children.list.length` 基本稳定，无内存泄漏迹象。
- [ ] 刷新页面后位置、时间、朝向从 `cbmu.save.v1` 恢复；不填 Key 也能恢复。
- [ ] 手动"存档"按钮提示"已保存"。

## NPC 与对话（M3/M4）

- [ ] 靠近 NPC 显示"E 交谈"提示；背对时不显示。
- [ ] E 键打开对话面板，可正常关闭；对话中 NPC 停止游荡、朝向玩家。
- [ ] 改变系统时间（或等待时钟推进）后，NPC 出现在日程对应的锚点/区域。
- [ ] 未配置 Key 时对话走预设台词，并标注"未配置 AI"。
- [ ] 配置 Key 后回复逐字流式上屏；按 Esc 立即停止请求。
- [ ] 错误兜底：故意填错误 Key（401）、错误 Base URL（CORS/断网）均给出人话提示并回退台词，不崩溃。
- [ ] 切到别的浏览器标签页（页面隐藏）时进行中的请求被中止。
- [ ] 设置里"清除对话记忆"后刷新，记忆不再恢复；不清则刷新后记忆仍在。
- [ ] 设置里"清除存档"后刷新回到初始状态。

## 昼夜与系统（M6）

- [ ] 时间推进时全屏色调按黎明/白天/黄昏/夜晚变化；夜间路灯点亮。
- [ ] 设置里切换时间流速 0.5×/1×/2×，时钟推进速度肉眼可见变化，保存后刷新仍生效。
- [ ] 三档界面字号（100/125/150%）正常，面板可用 Tab 遍历、Esc 关闭。
- [ ] 系统开启"减少动态效果"时昼夜改为跳变（如浏览器支持）。

## 内容完整性（M7）

- [ ] 五大书院、四大生活园、主要楼宇均有标识且地图连通无死角。
- [ ] NPC 游荡不穿墙、不卡死在障碍物里。
- [ ] 图情信息中心、弘医楼、临江书院、大学科技园、雅园食堂 5 个室内均可进入。
- [ ] 本地单图加载 < 3 秒。

## 边界用例

- [ ] localStorage 被禁用（隐私模式）：游戏仍可玩，设置降级为内存态，不抛错。
- [ ] 损坏的存档 / 记忆 JSON：不阻塞进入游戏，静默忽略。
- [ ] Base URL 带或不带尾部 `/` 都能正确拼接 `/chat/completions`。
- [ ] 旧版本存档（version ≠ 1）被拒绝并回到初始状态。
